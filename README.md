# 팁스타그램 스튜디오 · AI 모델 목록

팁스타그램 스튜디오 앱이 하루에 한 번 이 `models.json` 을 읽어서, 새 AI 모델이 있으면 "새 AI 모델이 나왔어요 · 업데이트" 안내를 띄웁니다.

- 모델 파일은 각 모델의 **공식 배포처**(GitHub Releases)에서 바로 받습니다. 이 저장소에는 목록만 있어요.
- 앱은 파일마다 `sha256` 을 확인하고 맞을 때만 바꿔 끼웁니다. 틀리면 기존 모델을 그대로 씁니다.
- `minApp` 보다 낮은 버전의 앱은 그 모델을 건너뜁니다(코드도 같이 바뀌어야 하는 모델).

## 바꾸는 법
1. 새 모델을 시험 영상으로 비교해서 더 좋은지 확인 (스튜디오 저장소의 `tools/bench`)
2. 라이선스가 상업적 사용 가능한지 확인
3. 해당 역할(`role`)의 `version`·`url`·`files[].sha256`·`size` 를 바꾸고 `updated`·`notes` 를 적어 커밋

| role | 하는 일 |
|---|---|
| vad | 말소리 구간 찾기 (무음 컷) |
| asr | 자막 인식 |
| person | 사람 영역 찾기 (누끼 기본) |
| matte | 정밀 누끼 가장자리 (선택) |
